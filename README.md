# puru TALK

說話就能打字的 Windows 語音輸入工具（繁體中文、英文），語音辨識與口氣改寫模型都內建、離線可用。朋友試用版。

- 下載：請到 [Releases](https://github.com/takhsu/puru-talk/releases)。
  - `puru-TALK-<版本>-setup-x64.exe`：安裝版（個人目錄，不需管理員）。
  - `puru-TALK-<版本>-app-win-x64.zip`：免安裝版；程式內的自動更新也是抓這個檔。
- Windows 若跳出「已保護您的電腦」：按「其他資訊」→「仍要執行」。程式尚未簽章。
- 隱私：預設不連網；說過的話只存在你電腦的 `%APPDATA%\puru-talk`。

此 repo 只放發布檔，原始碼不在這裡。問題回報：程式內「關於 → 反饋」。
